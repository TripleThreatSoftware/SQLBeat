# Contributing

Bug fixes and new checks are welcome. Open a pull request with a small, focused change and a note on how you tested it,
including the SQL Server versions you tested against.

Object scripts live one per file under `databases/<Database>/<type>/`. Keep the same layout and naming,
and don't commit passwords, server names or customer data.

By contributing, you agree that TTS LLC may distribute your contribution under SQLBeat's licenses,
currently the Apache License 2.0 with the Commons Clause condition.
